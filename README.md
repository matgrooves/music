# MatGrooves Artist Page

Page artiste simple pour GitHub Pages.

## Voir localement

Avec VSCode :
1. Prérequis: Installer l’extension Live Server.
2. Ouvrir `index.html`
3. Cliquer sur `Go Live` en bas à droite de la barre de statut

## Modifier les liens

Dans `index.html`, remplace les `href="..."` par tes vrais liens artiste :
- Spotify
- Apple Music
- Deezer
- YouTube Music
- Amazon Music
- Tidal
- Instagram

Le logo Deezer est intégré en SVG directement dans le HTML, donc il ne dépend d’aucune image externe.
